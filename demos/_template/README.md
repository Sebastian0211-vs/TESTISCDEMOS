## L’expérience proposée

Deux courts paragraphes : ce que voit ou manipule le public, puis ce que la
démonstration permet de comprendre. Éviter le jargon et les détails
d’implémentation.

## Déroulé conseillé

1. Le point de départ devant le visiteur.
2. L’action principale ou l’interaction proposée.
3. Le résultat à montrer et le message à retenir.

## À préparer avant l’événement

- Les vérifications concrètes à effectuer sur le stand.
- Le compte, le fichier ou le scénario à préparer.
- La solution de secours en cas de panne.

## Points d’attention

- Les limites à annoncer ou les manipulations à éviter.
- Les dépendances importantes comme le réseau, la lumière ou un matériel précis.
